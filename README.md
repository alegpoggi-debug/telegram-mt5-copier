# Telegram MT5 Copier

Copia su MetaTrader 5 i segnali dei canali Telegram scelti. App per Mac con aggiornamenti automatici.
Istruzioni: vedi [GUIDA.md](GUIDA.md).

Questo repository contiene solo il programma: nessun dato personale, nessuna impostazione, nessun accesso.
L'app scarica da qui gli aggiornamenti (file `VERSION`: la prima riga è il numero di versione, le righe seguenti le novità).
